# D2 LOD Files Directory

Place your Diablo II: Lord of Destruction 1.13c files here:

- d2data.mpq
- d2exp.mpq
- d2music.mpq
- d2sfx.mpq
- d2speech.mpq
- d2video.mpq
- game.exe
- and other required D2 LOD files

These files will be embedded into the D2RBot executable and automatically extracted when the application runs.

**Note:** This directory is ignored by git to prevent committing large game files.
